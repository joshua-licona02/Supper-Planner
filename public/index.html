Setting up Ollama on the other laptop
  1. Ollama only listens to its own laptop by default. To let this app reach it, set the environment variable OLLAMA_HOST to 0.0.0.0 and restart Ollama.
  2. Allow port 11434 through that laptop's firewall for your home network.
  3. Pull a model if you haven't: ollama pull llama3.1 (or qwen2.5, mistral, gemma3, and so on).
  4. Find that laptop's local IP address (for example, run ipconfig on Windows) and enter http://THAT-IP:11434 above.
